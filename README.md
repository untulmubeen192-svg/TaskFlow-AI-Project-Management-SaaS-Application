🚀 TaskFlow AI – Project Management SaaS

TaskFlow AI is a modern AI-powered Project Management SaaS frontend built using a single HTML5 file with embedded CSS and JavaScript.

The application provides a clean, responsive, and enterprise-inspired dashboard for managing projects, tasks, workflows, and team productivity. It is designed as a frontend prototype that demonstrates modern SaaS UI/UX principles.

✨ Features

- 📊 Interactive Dashboard
- 📁 Project Management
- ✅ Task Management
- 📋 Kanban Board
- 📅 Calendar View
- 🤖 AI Assistant Panel
- 👥 Team Collaboration Interface
- 📈 Analytics Dashboard
- 🔔 Notifications
- ⚙️ Settings Panel
- 🌙 Dark/Light Theme
- 📱 Fully Responsive Design
- ✨ Modern Animations & UI Components

## 💻 Technology Stack

- HTML5
- Internal CSS3
- Internal JavaScript (Vanilla JS)

> This project is built entirely inside a single `index.html` file without external frameworks or libraries.
